# Project Development Rules

- **ALWAYS** provide complete, full file contents when writing or replacing code.
- **NEVER** truncate code blocks.
- **NEVER** use "..." or "// TODO" or "// implement here" as shortcuts.
- **NEVER** generate pseudo-code.
- **ALWAYS** use production-ready, null-safe Dart code.
- **ALWAYS** ensure the code compiles without type mismatches or missing property errors.
- **STRICTLY** follow the UI/UX architecture: Material 3, rounded cards (12.0), compact Android-native feel.
